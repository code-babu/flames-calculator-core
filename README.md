## 📖 What is FLAMES?

FLAMES is a nostalgic schoolyard game popular across India, the Philippines, and Southeast Asia that determines the relationship destiny between two names through modular letter elimination:

- **F** — Friends
- **L** — Love
- **A** — Affection
- **M** — Marriage
- **E** — Enemies
- **S** — Soulmates (or *Siblings* in the classic 90s edition)

Read the full mathematical logic and rules guide at [FLAMES Calculator Rules & Guide](https://www.flamecalculator.in/flames-calculator-guide).
